While PurpleAir (PA) sensors are widely deployed for particulate matter monitoring, their simultaneous collection of meteorological data, including temperature, remains underutilized and lacks sufficient validation. 
This research assesses PA temperature accuracy by comparing measurements from collocated PA sensors and high-accuracy temperature data loggers across a dense urban network in a humid subtropical U.S. county. The details about sensor locations and their deployment protocols can be found at:

Liang, L., Daniels, J., Bailey, C., Hu, L., Phillips, R. and South, J., 2023. Integrating low-cost sensor monitoring, satellite mapping, and geospatial artificial intelligence for intra-urban air pollution predictions. Environmental Pollution, 331, p.121832.

This study also develops and compares calibration methods to create a replicable model using readily available crowdsourced data. The code provided offers the final selected model for interested users to modify.
